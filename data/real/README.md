# Real Public Data

This directory is reserved for downloaded public datasets used by analytics.

## Sources

- UCI Student Performance — UCI ML Repository dataset 320.
- UK Department for Education — Pupil Attendance, Week 37 2026.

Public datasets are kept separate from platform users, assignments, submissions,
and grades. Do not describe public-data rows as actual users of this application.

The DfE downloader records the actual acquisition timestamp and does not fabricate
or backdate historical observations.
